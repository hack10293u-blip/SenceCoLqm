# SenceLab

SenceLab là ứng dụng Android để xem kho map, nhập ZIP hoặc assetbundle và quản lý bản sao lưu của tệp map đã chọn.

## Tải ứng dụng

- [SenceLab v1.5.0 trên GitHub Releases](https://github.com/hack10293u-blip/SenceCoLqm/releases/tag/v1.5.0)
- Package Android `com.tmod.kgvn`
- Yêu cầu Android 8.0 trở lên
- Đây là APK debug để thử nghiệm

## Sử dụng

1. Mở **Kho Map** để xem các map có sẵn hoặc mở thư mục map trên Drive.
2. Nếu tải tệp từ Drive, mở **Nhập ZIP** để nhập ZIP hoặc `scene_artist_autochess_01.assetbundle`.
3. Bấm **Áp dụng** và chọn tệp đích mà Android cho phép truy cập. SenceLab sao lưu tệp gốc trước khi ghi và xác minh nội dung sau khi ghi.
4. Dùng **Gỡ map đang dùng** trên **Trang chủ** để khôi phục bản gốc.

Bản 1.5.0 làm mới danh sách thư mục map từ Drive. Ảnh xem trước và tệp bundle của các mục online được mở qua Drive. Việc ghi tệp phụ thuộc vào quyền mà Android cấp cho tệp đã chọn. Các mục Shizuku và ADB WiFi ở dạng mô phỏng.

Trong **Cài đặt chung → Kiểm tra**, ứng dụng tra cứu bản phát hành mới nhất trên GitHub Releases.
